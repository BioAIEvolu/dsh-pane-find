# DSH 分栏查找 · dsh-pane-find

在 DSH 桌面或 Web 界面按 **Ctrl+F / ⌘F**，或点击会话右上角、分享按钮左侧的放大镜。**`Ctrl+F` 在面板上次出现的位置打开（位置自动记住）**；**点击放大镜时面板出现在 🔍 下方左侧空白区，与图标同一高度**；**鼠标悬浮在面板边缘（光标变为十字移动箭头）即可拖拽到任意位置，松手后位置记住**。查找条能分别查侧栏、当前对话和右侧扩展面板。打开时会带入已选文字。

## 查找与定位

- 选择「对话」或「侧栏」，输入中文、英文或字面符号。相邻的行内样式标签可以组成同一个匹配。「侧栏」一次覆盖左侧会话栏和右侧面板这两块对话之外的区域（重叠部分只算一次）；两边都收起时临时切到对话，再展开会恢复侧栏。
- **Enter / Shift+Enter** 前后定位。F3 / Shift+F3 和 Ctrl/⌘+G 也可导航。**Esc** 关闭并清除高亮。
- 命中按出现位置计数。同一句话出现在不同消息里时，每一处都可单独定位。列表每页 12 条，最多保留前 5,000 个可定位范围，计数仍覆盖全部匹配。悬停查看当前消息的可见全文，点击「复制整条」写入剪贴板。
- 点击 **⋯ → 保存结果**，可在同一会话恢复查找。只有手动保存才记录查询词、栏、会话和位置校验信息，最多保留 20 条，保存在当前浏览器来源的本地存储中。点击「清除已存」清除本会话记录。消息改动或位置无法确认时，会重新列出当前命中供选择。
- 在 **⋯** 中点击当前快捷键，再按新组合键。颜色跟随宿主的主题。没有 CSS Custom Highlight API 的浏览器使用选区标出当前匹配。

查找范围是已经渲染的可见内容，包括打开的 Shadow DOM。折叠正文、iframe、编辑中的草稿及尚未加载的历史消息不参与搜索。展开折叠或收到流式追加时会重新计数。

## 会话工具

- 空输入框按 **↑** 取回最近的消息，继续按 ↑ 或 ↓ 浏览历史。每条可恢复最多六个附件。图片使用会话的原图引用。普通文件优先复用当前浏览器已在该会话上传的文件，在内存中合计最多保留 32 个、64 MiB。页面刷新或缓存被淘汰时，选择原文件后会核对文件名、字节数和 SHA-256。超过 64 MiB 的文件可通过宿主输入框手动添加。
- 在对话图片上悬停，点击 **复制图片** 写入 PNG。按钮会显示复制结果。图片权限受浏览器剪贴板与跨域策略约束。
- 已完成回答的 **重新生成** 按钮会通过当前会话再发一次对应的提问，原回答保留。附件需要完整恢复才能发送。最后一条已完成回答另有 **继续生成**。已有草稿、附件或会话正在运行时，按钮会保护当前输入。

## 本地构建与验证

工程为开源 MIT 开发包。当前 DSH 适配基线为 **0.2.2-rc.5**，客户端复用宿主提供的 React。源码目录下执行：

~~~sh
npm install
npm run build
npm test
npm run test:browser
~~~

浏览器回归需要 Playwright 支持的 Chromium。Windows 默认使用系统 Edge，可用 PANE_FIND_BROWSER 指定本机其他已安装的 Chromium channel。浏览器夹具使用内存剪贴板和会话接口替身。

本地包可以 link 到专用测试 profile。用解开的源码目录作为起点构建，或将已打包的 tgz 交给 DSH 的插件管理器。若同时启用多个注册 Ctrl+F 的查找插件，应分配不同的快捷键。
